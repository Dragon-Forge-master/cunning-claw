## Cunning Claw 0.5.1

**Real installers, Outlook, and the version on the glass.**

**New: installers.** Pick the one for your computer:

- **Windows:** `Cunning-Claw-Setup-0.5.1.exe`. Double-click, Next, Finish. No admin rights; Start menu and desktop icons; an uninstaller in Add/Remove Programs that keeps your keys and notes unless you tick the box.
- **Mac:** `Cunning-Claw-0.5.1-mac-arm64.dmg` (Apple silicon) or `-mac-x64.dmg` (Intel). Open it and drag Cunning Claw into Applications.
- **Linux:** `Cunning-Claw-0.5.1-linux-x86_64.AppImage` (or `-aarch64`). Right-click → Properties → allow it to run as a program, then double-click. Nothing to extract.

Not code-signed yet: Windows says "Windows protected your PC" (More info → Run anyway) and a Mac asks you to right-click → Open the first time. The zip and tar.gz downloads are still here for anyone who prefers them.

### New in 0.5.1

- **Installers that keep your things apart from the app.** An installed claw keeps your keys, settings, memory and workspace in your own folder (`%LOCALAPPDATA%\CunningClaw`, `~/Library/Application Support/cunningclaw`, or `~/.local/share/cunningclaw`). Updating is installing the new version over the old one; nothing of yours is touched. Coming from an unzipped download? Start it once with `--import <old folder>` and your keys, memory and notes come across. For installer users, commands in his sandbox can no longer change his own code (known gap 5, closed for them).
- **Outlook.** Outlook on the web, for Microsoft 365 work accounts and personal Outlook.com, through the same email tools as Gmail: check, read, draft, send (always on a card), archive, flag, delete. Set `"email": { "provider": "outlook", "outlook": "work" }` (or `"personal"`) in `claw.config.json` and sign in once in his own Chrome. Every email is a stranger's words; a button inside an email body is never pressed. Gmail is unchanged and stays the default.
- **The version beside the logo.** The HUD shows which version is running, and says "updated" the first time you open it after an update.

### Not yet tried for real

- **Outlook** was tested against a page built to Outlook's accessibility structure in a real browser, not against a real Microsoft account. If something doesn't match, a screenshot is enough to fix it.
- **The installers** were each installed, started and checked on GitHub's own Windows, macOS and Linux machines before release; the Mac's Finder-to-Terminal step and the Intel `.dmg` and ARM AppImage have not been started on real hardware.
- Everything listed as untried in [0.5.0](v0.5.0.md) still is.
