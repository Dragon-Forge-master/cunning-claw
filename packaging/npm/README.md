# cunningclaw

**Y dyn hysbys — the knowing one.** A local-first AI butler that runs on your
machine and actually operates it: sees the screen, runs the shell, reads the
mail, speaks back — and refuses when a web page tells it to do something you
didn't ask for.

This package is the one-command installer:

```bash
npx cunningclaw
```

It checks Node 22+ and git, clones the repository, and installs — then tells
you exactly how to start. The claw itself lives at
[github.com/Dragon-Forge-master/cunning-claw](https://github.com/Dragon-Forge-master/cunning-claw).

> **Yn lleol yn gyntaf · Caniatâd dynol pan fo canlyniadau**
> *local first · human consent where there are consequences*

This is the only official npm package for Cunning Claw. There is no Cunning
Claw token or coin, and there never will be.
